# Architectural Decision Records

Use this directory for short records of decisions that are expensive to rediscover later.

## Naming

Use one file per decision with a date prefix:

```text
YYYY-MM-DD-short-title.md
```

## Suggested Template

```md
# Decision Title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD

## Context

What constraints or forces matter here?

## Decision

What was chosen?

## Consequences

What becomes easier, harder, or riskier because of this choice?
```
